# 3-
## Штормовое ядро

Трёхмерная браузерная аркада с 24 уровнями, десятью кораблями и видом из кабины. Расследуй исчезновение ковчега «Аврора» и заработай корабли в вылетах. Игровые файлы лежат в `docs/`. GitHub Pages публикует ветку `main` из корня репозитория. Корневая страница открывает игру в `docs/`.

[Играть в браузере](https://kopejkingeorgij09-web.github.io/3-/)

- На компьютере используй WASD или стрелки для манёвра, пробел для огня, Shift для форсажа и Esc для паузы.
- На телефоне управляй левым джойстиком. Огонь автоматический, форсаж включается отдельной кнопкой.
- Для переноса прогресса придумай позывной и сохрани весь код с секретным суффиксом. На другом устройстве выбери «Войти по коду».

Для игры с локального компьютера открой `docs/stormcore.html` в браузере или запусти `python -m http.server 8000 --directory docs`. Интеграция с Supabase использует публичный URL функции из `docs/cloud-config.js`. В `supabase/` лежат миграция и исходник функции сохранений.
