БОРТОВОЙ ИНСТРУКТАЖ

Управление

WASD / стрелки
Короткое нажатие сдвигает корабль. Удерживай клавишу для полного разгона.
C
Удерживай вместе с направлением для точного манёвра у осколка или прицела.
Пробел
Удерживай для огня. Направляй корабль и бери упреждение на движущихся целях.
Shift
Форсаж даёт временную неуязвимость и удваивает очки.
Esc
Пауза, чувствительность и выбор вида из кабины.
Сенсорный экран
Мягко отклоняй джойстик для мелких поправок курса. Огонь автоматический.

Q стреляет ультой при полном заряде. Собирай осколки и попадай по целям, чтобы зарядиться быстрее. На снайперских кораблях E включает оптику и точный ход. Прицел наводится движением корабля.

Совмести метку осколка с кольцом перед носом, пока он приближается. Бирюзовые осколки заряжают форсаж. Голубые маяки дают очки и пополняют корпус. Когда над врагом горит «ЗАЛП», смени курс.
